# Password Generator 🔐

A simple Password Generator mobile application built using React Native and TypeScript.

## Features

- Generate random passwords
- Choose password length
- Include lowercase letters
- Include uppercase letters
- Include numbers
- Include symbols
- Form validation using Formik and Yup
- Reset password options
- Copy/select generated password

## Technologies Used

- React Native
- TypeScript
- Formik
- Yup
- React Native Bouncy Checkbox
